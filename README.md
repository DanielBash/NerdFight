# Nerd Fight

> Веб-сайт для садистов, которым не хватает школьных задач.

Nerd Fight - интернет ресурс для быстрой и интуитивной подготовки к олимпиадным соревнованиям по математике. Создан маленькой командой разработчиков для предпрофессиональной олимпиады школьников.
Развернут на [этом](https://nerdfight.ibashlhr.beget.tech) веб-сайте.

## Локальный запуск
1) Скачать репозиторий проекта
```bash
git clone https://github.com/DanielBash/NerdFight.git
cd NerdFight
```

2) Установить зависимости
```bash
pip install -r requirements.txt
```

3) Запустить скрипт
```bash
python main.py
```
